
# ⚡ Electronics Toolkit

A beginner-friendly electronics calculator built using C.

## Features

- Ohm's Law Calculator
- Calculates resistance using voltage and current
- Handles zero-current input

## Formula

R = V / I

Where:
- R = Resistance (Ohms)
- V = Voltage (Volts)
- I = Current (Amperes)

## Technologies Used

- C Programming
- GCC Compiler
- Visual Studio Code
- Git & GitHub

## How to Run

Compile:

```bash
gcc resistance.c -o resistance.exe
```

Execute:

```bash
./resistance.exe
```
